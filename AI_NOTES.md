# Development Workflow

Rather than asking AI to build the entire project, I followed a structured development process.

1. I first analyzed the assignment requirements and understood what needed to be built.
2. I broke the project into smaller development tasks and planned the implementation.
3. I created the project structure and organized the files manually.
4. I prepared detailed prompts describing my own ideas, API requirements, validation rules, and expected behavior.
5. AI generated an initial implementation based on my requirements.
6. I reviewed every generated file, understood the logic, modified the implementation where necessary, and tested the final application.

This approach allowed me to learn the concepts while significantly reducing development time.

# My Perspective on Using AI

This project reinforced my belief that AI should be used as a **development assistant**, not as a replacement for learning.

My approach was:

- I first understand the problem before asking AI for code.
- I provide my own ideas, requirements, and implementation approach to the AI.
- I review every generated section before accepting it.
- I modify the generated code to match my understanding and project requirements.
- I never blindly copy and paste AI-generated code.
- I validate, test, and maintain the final implementation myself.

Using this workflow, I completed this assignment in approximately **3 hours**. Without AI assistance, I estimate the same project would have taken **around one full day**. AI significantly reduced development time by automating repetitive coding tasks, allowing me to spend more time understanding the implementation, validating the logic, debugging issues, and improving the overall quality of the project.

For me, responsible AI usage means **learning first, prompting second, validating always, and taking ownership of the final product**.
